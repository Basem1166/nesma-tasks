# Candidate Technical Assessment
## AI-Powered Team Communication & Task Management Platform

### Objective
Develop a fully functional web platform for team communication, task management, workflow automation, and AI-powered reporting, supported by a high-quality mobile application.

### Required Features

1. *Authentication & Access Control:* Secure login, individual credentials, and role-based access for team leaders and team members.
2. *Task Management:* Create and assign tasks, set deadlines and priorities, track progress, and monitor overdue and completed tasks.
3. *Automated Notifications & Emails:* Automatically send emails for task assignments, updates, approaching deadlines, and overdue tasks.
4. *AI-Powered Reporting:* Generate monthly reports using actual application data, covering completion rates, team performance, delays, and achievements.
5. *AI Chatbot:* Allow authorized users to retrieve task information, analyze progress, and generate summaries through natural-language questions.
6. *Workflow Automation:* Integrate task assignments, progress updates, reminders, notifications, and reporting into one seamless workflow.
7. *Mobile Application (A Key Factor in Candidate Selection):* Develop a high-quality, fully integrated mobile app featuring task management, progress tracking, push notifications, and team communication, seamlessly synchronized with the web platform.

### Deliverables

- Functional web application and mobile app.
- Complete source code and database structure.
- Workflow diagram.
- Setup and deployment documentation.
- Secure configuration instructions for credentials, email services, and AI APIs.
- Testing evidence and a working demonstration.

### Evaluation Criteria

Candidates will be evaluated on functionality, workflow automation, AI integration, mobile app quality, security, user experience, code quality, and reliability.

*Important:* A static prototype is not acceptable. Candidates must demonstrate working features, functional integrations, and AI capabilities connected to actual application data.

### Expected Outcome

Deliver a secure, scalable, and reliable platform that streamlines team operations through AI and automation, with a high-quality mobile app that significantly enhances accessibility and productivity.
